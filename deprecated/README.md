# Retired configurations

Historical reference, outside the maintained CLI and local checks.
Contents and original file permissions are preserved; installers are not maintained.

- `.config/`: Awesome, i3, Polybar, Picom, Dunst, Rofi, Kitty, Nitrogen,
  Redshift, and Chromium flags.
- `*-install.sh`, `*-config*.sh`: old Arch, Debian, macOS, and desktop setup scripts.
- `.zshrc`, `gitconfig`, `windows-terminal.json`: previous shell/Git/terminal settings.
- `arc/`, `fonts/`: GNOME extensions and bundled fonts.
- `laptops/X1C8/`, `liquidctl/`: retired ThinkPad fixes and NZXT hardware settings.

Relative paths are retained for reference. Moving these files does not change
installed configuration. Restore individual pieces deliberately if needed again.
